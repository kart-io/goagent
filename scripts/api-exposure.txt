# 稳定包导出 API 传递暴露的非稳定类型：<标识符> <模式>，由 scripts/exposurecheck 校验。
# 标识符为相对模块根的包路径加类型名；模式见 docs/API_STABILITY.md「传递暴露」：
#   full     调用方实现、赋值或构造：冻结底层类型、方法集与该类型的导出常量
#   identity 原样透传的不透明句柄：只冻结类型名与所在包
#   alias    类型别名：冻结指向
# 新增暴露必须在此登记；已不再暴露的条目必须删除。

cache.Cache            full      # tools/middleware.CachingConfig.Cache、WithCache：调用方实现或传 NewSimpleCache
cache.CacheStats       full      # cache.Cache.GetStats 的返回值

constants.Provider     full      # llm.Client.Provider() 等：实现 llm.Client 时必须使用

utils/httpclient.Client full     # llm/common.BaseProvider.NewHTTPClient 的返回值
utils/httpclient.Config full     # httpclient.Client 方法签名引用
