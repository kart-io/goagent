# 运维 AI 案例：规则先行、证据可核、模型只能降级

五个案例演示运维场景下常见的 AI 能力（告警诊断、SQL 变更审核、容器容量建议、费用问答），用 goagent 实现。业务数据全部是合成的，不连接任何真实系统。

| 案例 | 场景 | 验证的设计 | 关键断言 |
| --- | --- | --- | --- |
| [告警根因](alert-rca/README.md) | 5xx 升高，从指标、日志、变更中找根因 | 结论证据逐字引用工具结果；核对不通过交还模型修复，次数有上限 | 根因正确；证据全部通过核对；修复次数用尽即中止 |
| [SQL 工单审核](sql-review/README.md) | 一批 SQL 变更工单 | 规则门禁先判，模型只能否决或升级；严格 JSON；审批暂停期间工单被改就作废 | 规则拒绝的工单不调用模型；只有 approve+low 的 test 工单自动执行；改动后不执行 |
| [容量两层复评](capacity-review/README.md) | 12 个工作负载的扩缩容建议 | 批量初筛 + 子 Agent 逐项深评；数值护栏；AI 只能降级规则结论 | 可执行项同时满足三个条件；保持与证据不足的项永远不可执行 |
| [费用归因](cost-attribution/README.md) | 9 月比 8 月涨在哪 | 金额只由代码计算；多币种不相加；空值不是 0；按账号授权；宿主复算结论 | 得出 `USD/ai`；summary 中的数字都出自工具结果；越权查询中止 |
| [受限子调查](scoped-lookup/README.md) | 下单延迟升高，按方向派出子调查 | 每个子调查只授权一个工具；同轮并发；禁止嵌套；父子共用证据账本 | 子会话只调用授权工具；嵌套被拒；结论能引用子调查内部的证据，崩溃恢复后仍可核对 |

## 示例层能力

以下能力放在 [opscase](internal/opscase/opscase.go)，建立在框架的 Dispatcher（参数错误交还、`OnResult`）与 Builder（`WithReturnDirectTools`、`WithEmptyAnswerRetries`、同轮工具并发）之上：

- `Dispatch`：开启 `ReturnArgumentErrors` 的 Dispatcher，参数错误交还模型改正。并发上限沿用框架默认值。
- `Ledger`：给工具结果编号，结果以字符串交给模型。
  - 持久调用的引用号由执行键（父键 + CallID 派生）摘要取 6 位十六进制，形如 `E3fa29c`。同一轮并发执行时编号与完成顺序无关，重启后不变，父子会话共用一本账也不会撞号；万一两个不同结果撞号，登记时报错中止。
  - 结果只经 `DispatchConfig.OnResult` 登记：首次执行与日志回放走同一路径，调查中途崩溃后账本随回放重建。
  - `Verify` 核对结论引用的摘录：必须是该结果中按原顺序连续的一段（可跨字段，JSON 引号、括号、逗号可省略），首尾不能截断。截断数字、丢掉负号（`-100.00` 摘成 `100.00`）、截断单词（`checkout-api` 摘成 `-api`、`31/200` 摘成 `/200`）、只摘字段名、改写内容或调换顺序都不通过。
- `Submitter`：`submit_conclusion` 的通用实现。核对证据与附加检查，不通过作为参数错误交还模型，修复次数有上限。通过时返回由结论渲染的最终回答（首行“结论：…”），配合 `WithReturnDirectTools` 直接结束运行，不再请求模型复述。被接受的结论由 `OnResult` 从提交调用的参数中取出，回放时同样恢复，宿主不另行落盘。
- `StrictJSON`：只接受一个 JSON 对象（可包在一个代码块里），字段名区分大小写，拒绝未知字段、重复键和多余内容。

核验的边界：`Verify` 只证明摘录确实出自所引用的那次工具结果，**不证明摘录支撑结论**。模型可以原样摘录一段无关的日志，再给出错误的根因；结论是否成立由各案例的附加检查（如费用归因复算最高涨幅）或人工判断。

## 运行

环境变量与 [live 案例](../live/README.md#运行) 相同。

```sh
go test ./examples/orchestration/ops/...                                     # 离线：脚本化模型
GOAGENT_LIVE=1 GOAGENT_LIVE_PROVIDER=deepseek go test -race -v ./examples/orchestration/ops/...
```

测试断言的是按规则应得的结论和编排不变量（请求数等于根预算预留、回放 0 次请求、子会话创建数等于清理数等）。告警根因、费用归因、受限子调查的最终回答由已核验的结论渲染，不采信模型的自由文本。
