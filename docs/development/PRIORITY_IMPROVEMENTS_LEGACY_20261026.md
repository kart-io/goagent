# 按优先级推进的能力完善

基线：`12c8aae`。保留已有调用入口，在可验证的行为上增强 goagent。

| 顺序 | 范围 | 验收 | 状态 |
|---|---|---|---|
| P0 | Retriever 执行契约 | Invoke/Stream/Batch/Pipe 与直接检索一致，配置克隆、回调、错误和取消可验证 | 本轮完成 |
| P1-A | 中文检索、真实重排序、引用评测 | 固定数据集报告召回与引用指标，真实模型评分不使用模拟回退 | 本轮完成 |
| P1-B | RAG＋工具＋模型流 | 单一事件入口包含来源、步骤、文本、用量、错误和取消 | 本轮完成 |
| P2-A | MCP 与持久化恢复 | 官方 SDK 协议互操作；重启后从持久化位置继续；幂等键明确 | 本轮完成 |
| P2-B | 推理策略评测 | 同题、同模型、同预算记录成功率、调用数、Token、耗时和成本输入 | 本轮完成 |

没有业务数据时使用明确标注的合成数据；合成评测不代表真实业务效果。不同协议、模型能力及恢复语义的限制在对应指南记录。

实现与边界见 [能力指南](../guides/PRIORITY_CAPABILITIES.md)，命令与原始测量见 [评测记录](../evaluation/README.md)。

本轮验收：全仓短测试；新增/变更核心包竞态测试；Go 1.25 golangci-lint v2；DeepSeek 真实 RAG、流式和策略运行。P2-A 提供显式顺序步骤恢复与 SDK 工具客户端，不等同于通用图调度、任意 Agent 栈恢复或完整 MCP 服务端平台。补充轮已实现 ReAct 格式兼容与可选受限重试、ToT 最终答案契约、严格错误传播与全阶段用量统计；复测结果见评测记录。
