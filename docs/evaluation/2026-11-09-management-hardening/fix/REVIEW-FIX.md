## 边界

取消后的补偿有独立 OpTimeout，返回可能晚于调用方期限；清理失败仍通过 OnError 报告并由 TTL 兜底。成功交付后的取消仍由调用方执行 unlock。租约协议要求所有并发实例使用相同 advisory 锁方案。

报告门禁验证已有事件流的结构、契约和统计，不提供来源认证，也无法证明一个在日志与摘要中同时完整缺失的非必需包曾运行。启动期限不是全矩阵共用期限；非 Unix 沿用原有进程取消边界。

此次验证不包含真实业务环境、生产容量、长时间负载或主备切换验收。前轮短时 soak 与文件预算分配开销观察保留，本轮没有将其改写为性能改善结论。独立 agent 复审不等于人工签字。
