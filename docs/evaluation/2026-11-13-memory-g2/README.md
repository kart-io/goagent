# 记忆 G2 派生与整理：真实模型评测（2026-11-13）

对应设计 `docs/design/MEMORY_G2_DERIVATION.md` 第 8 节的评测：G2（关系派生、回退切开轮次、Worker 单次提交）完成后，用 `scripts/memeval` 重新灌入 LOCOMO 分层 200 题，graph 准确率应落在 46–60%。

## 设置

- 代码：`31dc82e9`（G2a–G2d 与 G2e 文档）。
- 数据：LoCoMo `locomo10.json`（官方仓库 `snap-research/locomo`，sha256 `79fa87e9…98ff4`），按题型分层抽 200 题，用同一份代码独立跑 2 次，每次重新抽取记忆；与 G0、G1 评测抽到的题目逐一相同。
- 模型：抽取与作答 deepseek（温度 0），判定 `gpt-4o-2024-08-06`，嵌入 `gemini-embedding-001`，与 G1 相同；评测时钟固定（`Config.Now`）。
- 抽取提示词增加了关系的 `from`，抽取请求与 G1 不同，所以所有请求都直接调用模型，没有录制回放；结果含抽取波动。
- 命令：

```bash
go run ./scripts/memeval -format locomo -data locomo10.json -sample 200 -repeats 1 -concurrency 10 \
  -systems memory,graph -chat deepseek -judge openai:gpt-4o-2024-08-06 -embed gemini:gemini-embedding-001 \
  -out locomo-200.md -results locomo-200.jsonl
```

第 2 次只把输出改为 `locomo-200-r2.md`、`locomo-200-r2.jsonl`。

## 结论

- graph 两次分别为 50.5%、51.0%，合计 203/400 = 50.8%（Wilson 95% 区间 46–56%；同一批题跑两次不独立，这个区间偏窄），在验收区间 46–60% 内。与 G1 各轮的差异都不显著（p ≥ 0.54），各题型的答对数相差不超过 3 题。
- 两次之间几乎没有波动：graph 逐题 17 胜 16 负，memory 16 胜 15 负；graph 各题型的答对数相差不超过 1 题，memory 不超过 2 题。
- memory 两次分别为 48.0%、48.5%，比 G1 默认高 3.5–4 个百分点，差异不显著（p ≥ 0.28）。
- 证据召回上升（memory 76% → 95%，graph 83–85% → 87–91%）主要来自计量口径：非对抗题平均每题覆盖的会话，memory 从约 13 个增加到约 23 个，graph 从约 14 个增加到约 18 个。G2 的合并记录取全部展示候选的来源并集（`mergeInto`），G1 只继承被更新记录的来源；关系的来源也从一条变为每次派生一条。诊断中 conv-26 每条有效记录平均带 3.0 个来源，G1 为 1.4 个。召回率与 G1 不可比，准确率也没有随之提高。graph 未召回到证据的题（第 1 次 20 题，第 2 次 14 题）全部答错。
- graph 上下文缩短（约 2700 → 1750 字）的原因是 G2 不再产生超长的合并记录，不是关系失效。缩短集中在部分对话（如 conv-42 3776 → 1431、conv-48 4018 → 1363），conv-26、conv-43、conv-47 两边相同。对 conv-48 用两份代码各灌入一次并统计（只抽取与召回，不作答）：
  - G1 有效事实 51 条、平均 179 字，召回到的事实行约 1000 字一条，3–5 条就接近 4000 字预算；G2 有效事实 78 条、平均 101 字，召回到的事实行 60–290 字。
  - 召回块中记录与关系分别为 G1 3618 / 253 字，G2 1220 / 462 字；G2 召回的关系更多。
  - 反思两边都是 12 条，召回中每条约 50 字，不是原因。
  - G2 的关系 98 条有效、2 条 underived（依据记录被替代），G1 为 108 条；关系因派生失效而减少的影响很小。
  - G2 为什么不再产生超长合并记录（锁外一次规划、同一任务内的候选不再逐条滚动并入同一条记录，或者抽取波动）未逐一验证。准确率没有下降，召回块只用了约 45% 的预算，提高 `RecallK` 可能还有空间。

逐题结果见 `locomo-200.jsonl`、`locomo-200-r2.jsonl`，汇总见对应的 `.md`，运行日志不保留。第 2 次有 1 道 memory 题（conv-44/88）召回为空。
