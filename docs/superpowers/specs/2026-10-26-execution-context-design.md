# 执行入口、上下文治理与 Eino 对照

用户已要求执行功能对比中的建议。本轮沿用 GoAgent，新增可选上下文治理，提供独立 Eino 对照模块；不改变旧 Execute 的语义。

## 方案与取舍

沿用 Builder 能保留工具、RAG、中间件和评测资产。直接替换为 Eino 会扩大接口及状态迁移范围；自建完整 Graph 编译器暂缺实际业务需求。因此先收敛公开入门文档到 AsRunnable，以独立模块验证 Eino 编排。

## 行为

- ContextPolicy 默认关闭，仅在 Builder 原生工具流使用；不支持的 Provider 或无工具配置在 Build 时明确报错。
- 按完整工具回合保留最近结果。旧的大结果保存到执行内存，以带引用的消息替代，角色、调用 ID、reasoning_content 保持原样。内置 read_context_result 工具按 Unicode 字符分页读取，引用仅当前执行有效，不提供任意文件读取。
- 最后一个模型请求恢复已卸载原文，避免失去读取机会；最终请求不保证缩小。
- 排除名单和内置读取结果不做卸载。工具直返仍输出完整原文。阈值是字符数而非 Token，也不是内存上限。
- 可显式配置历史摘要模型，超过字符阈值时只摘要旧的普通对话，保留 system、最近消息和当前问题。摘要作为不可信历史数据放在 user 消息，不提升为 system 指令；不修改持久化记忆。
- 摘要增加一次模型请求，计入 MaxIterations 和累计用量；至少预留一个任务模型请求，错误、截断、空摘要、取消均传播。没有摘要用量时完整用量标记为 false。
- Eino 放在独立 Go 模块，固定发布版本，不增加主模块依赖。复用题集、提示、计量和评分，验证普通回答、工具循环、直返、错误和预算。默认只生成任务，在线调用必须显式 -live。
- 提供无模型的 Eino 分支工作流示例，复用 GoAgent Runnable，作为适配验证；不声称跨进程可靠调度或正式迁移。

## 验收

新增行为先写测试，覆盖 Unicode 分页、工具协议、跨执行隔离、保留与排除、摘要预算和用量、失败与取消；主模块短测试及修改包 race 检查；独立模块测试、离线对照与工作流示例。无真实业务标签时不编造生产成功率，也不把假模型用作性能排名。
