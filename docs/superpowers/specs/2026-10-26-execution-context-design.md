# 执行入口与上下文治理

用户已要求执行功能对比中的建议。本轮沿用 GoAgent，新增可选上下文治理；不改变旧 Execute 的语义。

## 方案与取舍

沿用 Builder 能保留工具、RAG、中间件和评测资产。公开入门文档统一推荐 AsRunnable，复用原生工具执行源。

## 行为

- ContextPolicy 默认关闭，仅在 Builder 原生工具流使用；不支持的 Provider 或无工具配置在 Build 时明确报错。
- 按完整工具回合保留最近结果。旧的大结果保存到执行内存，以带引用的消息替代，角色、调用 ID、reasoning_content 保持原样。内置 read_context_result 工具按 Unicode 字符分页读取，引用仅当前执行有效，不提供任意文件读取。
- 最后一个模型请求恢复已卸载原文，避免失去读取机会；最终请求不保证缩小。
- 排除名单和内置读取结果不做卸载。工具直返仍输出完整原文。阈值是字符数而非 Token，也不是内存上限。
- 可显式配置历史摘要模型，超过字符阈值时只摘要旧的普通对话，保留 system、最近消息和当前问题。摘要作为不可信历史数据放在 user 消息，不提升为 system 指令；不修改持久化记忆。
- 摘要增加一次模型请求，计入 MaxIterations 和累计用量；至少预留一个任务模型请求，错误、截断、空摘要、取消均传播。没有摘要用量时完整用量标记为 false。

## 验收

新增行为先写测试，覆盖 Unicode 分页、工具协议、跨执行隔离、保留与排除、摘要预算和用量、失败与取消；主模块短测试及修改包 race 检查。无真实业务标签时不编造生产成功率，也不把假模型用作性能排名。
