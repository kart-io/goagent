# GoAgent 执行可靠性与治理设计

用户授权：先分析并给出执行计划，无阻塞问题即全面执行。本设计以 1cba257 为基线。

## 目标与方案

采用现有执行源、操作日志和根预算上的增量改进；不重建运行时，不把 Harness 组件迁回核心。
替代方案为只修 P0（无法兑现宿主运维能力）或一次重写执行框架（扩大恢复兼容风险）；选择分任务增强，逐项测试并提交。

## 交付范围

1. Builder 初始化严格传播 Exists/Load 错误及状态类型错误，失败不调用初始化回调、不替换原状态。记忆默认尽力模式；可选严格模式传播读写错误。尽力模式输出结构化观察事件，不向 stderr 直接输出原始错误；错误事件不包含对话或原始错误。所有入口保持已声明能力限制。
2. Pipe、Sequence 复用 StreamRunnable 的单一终态、回调和取消规则。上游仍 Invoke 后下游 Stream，不变为逐 token transform。空 Sequence 为恒等变换。上游失败不执行下游，缺失/重复终态及迟到错误不得成功；消费者取消后生产者退出。第三方不响应 ctx 的函数无法强制终止，明确边界。
3. 新增只读运行诊断，复用已知 RunID、快照与显式 operation ID，不扩充 Store 强制接口。区分完成、审批等待、pending 结果未知、失败、恢复版本/计划不匹配，输出恢复动作建议；不输出模型内容和工具结果，不自动重跑、不批准。支持 core/durable Runner 与 workflow 图报告。
4. 根预算增加可选工具调用总次数、绝对截止时间、保守 Token 预留及用量差额统计。Token 预估通过宿主注入的函数提供；配置 Token 上限却没有可靠预估时准入失败。已预留额度不因取消或崩溃退回，实际用量可超过估计，须明确这不是提供商实际费用硬上限。子调用共享根预算；金额换算与独立子任务配额交宿主，避免凭空引入价格或租约。无新限制时兼容现有请求额度与旧日志，配置变化拒绝旧运行。
5. 增加有界异步观察适配器（非阻塞入队、丢弃统计、可取消关闭、隔离 panic，阻塞 observer 只占固定 worker）；Pipeline 会话授权可按 TTL 清理。Dispatcher 分离准入和执行并发、提供可选排队上限与可识别繁忙错误，等待审批不占用执行槽位，所有等待仍受宿主 ctx 约束。默认保持原有执行并发与兼容行为，关闭/超时不产生额外隐式执行。
6. 基于已有本地 HTTP/SSE 服务与 Provider 回归工具扩充共享契约测试，覆盖 OpenAI、DeepSeek、Gemini 已支持的工具流：完整工具参数、finish reason、中断、取消、usage 缺失与错误分类；不启用真实付费模型调用。
7. 文档明确推荐入口、扩展机制错误/重放/超时/并发语义、稳定与实验能力、GoAgent/Harness 版本验证方式。旧规划归档提示，新增当前优先级和发布清单。兼容 Harness v0.23.0 公开接口，不强制删除旧同步入口。

## 验收与发布

新增行为先失败再实现；持久预算覆盖重启、并发与未知用量；资源治理覆盖满队列、取消、关闭及回收；全量普通及 race 测试通过。
新功能 opt-in；不可避免的语义修复标明迁移。使用 Harness 公开 API 集成测试验证本地两个模块。所有工作只做本地提交，不自动 push、tag 或发布。

## 计划审阅修正（已采纳）

- 新增预算 Config 字段禁用时必须 JSON omitempty，保持旧模型 intent 的字节结构；estimator 作为运行时函数，不进入持久 Config，以稳定策略版本标识估计规则。测试旧 ledger 与旧 completed model operation 的实际恢复。
- Dispatcher 两段排队只受宿主 ctx 约束；校验、授权、日志和执行累计消耗原 Timeout，准入及等待执行槽暂停计时。取得执行槽后重查取消；审批不再占执行槽是有意语义修复，须在迁移说明明确。
- 无操作证据的未完成 Runner/Graph 报告为执行结果未知，不能推断失败或建议无条件安全重跑。failed/pending 仅来自显式操作记录。
