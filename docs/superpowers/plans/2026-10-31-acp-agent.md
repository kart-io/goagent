# ACP Agent 端实施计划

> **执行要求：** 使用 superpowers:executing-plans 逐项执行；本计划无需并行代理。每项先写失败测试，再实现并本地验证。下列复选框记录未来实现进度，修订计划不等于功能已完成。

执行状态：已获取 contrib 的 a21455c 基线，确认其已有 ACP 实现及部分修复，因此本轮按差异实施而非重建。实际结果、既有 io.Closer 与已修正的安全 load 约定及验证记录见 [执行记录](../../../../goagent-contrib/docs/ACP_CONTRACT_FIXES.md)。下列初始化流程保留供追溯，Neovim/CodeCompanion headless 真实客户端联调现已完成，图形界面操作仍未验证。

**目标：** 在 goagent-contrib 的独立 acp 模块实现编辑器驱动的普通 GoAgent Agent，并在 examples 给出可运行案例。

**架构：** SDK 负责协议分派，适配层拥有会话取消、资源生命周期、工具通知、环境转发和持久元数据。Factory 不要求 Harness；GoAgent 核心不依赖 ACP。

**技术栈：** Go 1.25.0、goagent v0.32.0、acp-go-sdk v0.13.5、uuid v1.6.0、testify v1.11.1。

**规格：** [ACP Agent 端设计](../specs/2026-10-31-acp-agent-design.md)。2026-10-31 根据[调研报告](../../research/2026-10-31-new-plugin-acp-review.md)修订；本版替换旧计划中的完整代码草稿，避免实现按已知有缺陷的示例继续编写。

## 全局约束

- 模块路径 `github.com/kart-io/goagent-contrib/acp`，目录 `goagent-contrib/acp/`，`go 1.25.0`；依赖固定为上方版本。SDK 别名 acpsdk。
- 不修改 goagent 主模块，不修改/复制 SDK 私有取消表。session/cancel 必须主动调用适配层状态，不能留空。
- 所有文档、注释、错误、测试描述与提交说明使用简体中文；错误以 `acp: ` 开头，包装错误保留 errors.Is/As。
- JSON-RPC 使用 SDK NewInvalidParams/NewMethodNotFound/NewInternalError；本地清理错误先保留 Go 错误链，协议转换时携带可读文本。
- 日志写 stderr；stdout 只写 ACP。MCP/插件资源以 Session.OnClose 登记，未登记资源由宿主负责。
- 新模块在 contrib 的 feat/acp 分支实现；examples 使用 feat/acp-example。先检查实际仓库路径与现有脚本，不复制旧计划的机器绝对路径。
- 每项执行 `go test -race -count=1` 对应测试；全部完成后 `go vet ./...`、`go test -race -count=1 ./...`、现有 lint 与仓库测试入口。只记录实际执行结果。
- 主仓文档修订、模块实现、真实编辑器联调、发布分别记录；未经执行的测试不得勾选。合并、推送、打 tag 不由本计划自动执行。

## 复核重点

1. 同 Session 第二/第三个 prompt 替换旧请求后仍可取消：任务 2。
2. 取消/关闭发生在 Factory、等待执行权或审批期间，清理仍恰好一次：任务 2、4。
3. 命令长于 5 秒再结束/取消，回收 context 仍有效，远端不明结果可见：任务 6。
4. 两个重叠工作区并发条件写、缺少父目录、单侧文件能力：任务 5。
5. 缓存仅有 done.Output、跨连接 cwd 丢失或回放失败：任务 3、7。
